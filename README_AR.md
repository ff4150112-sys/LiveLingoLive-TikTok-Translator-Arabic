# LiveLingo — نموذج أولي Android

هذه نسخة بداية (Prototype) وليست تطبيق ترجمة مكتملًا بعد.

## ما الذي يعمل الآن؟
- شاشة رئيسية بسيطة.
- طلب إذن الظهور فوق التطبيقات.
- نافذة عائمة تجريبية فوق التطبيقات.
- إشعار foreground أثناء تشغيل الخدمة.

## ما الذي لم يُنفّذ بعد؟
- التقاط الكلام والتعرّف عليه.
- تحديد اللغة تلقائيًا.
- ترجمة النص إلى العربية.
- قراءة الترجمة بصوت عربي.

## طريقة الفتح
1. فك ضغط الملف.
2. افتح مجلد `LiveLingo` باستخدام Android Studio.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على هاتف Android أو محاكي.

## ملاحظات مهمة
- يلزم Android 8.0 أو أحدث.
- سيطلب التطبيق إذن الميكروفون وإذن الظهور فوق التطبيقات.
- هذه النسخة لا تتجاوز قيود TikTok أو Android. التقاط صوت تطبيق آخر ليس مضمونًا؛ بعض التطبيقات تمنع مشاركته. يمكن اختبار الميكروفون كحل بديل في المرحلة التالية.
- لا ترفع مفاتيح API أو كلمات مرور إلى المشروع.
